Built an interactive 4-page Power BI dashboard to analyze a multi-fund investment portfolio, covering AUM trends, risk-adjusted fund performance, cash flow activity, and investor composition. Designed a star-schema data model across 6 tables and wrote custom DAX measures for Sharpe Ratio, Alpha vs. Benchmark, and Return Volatility to benchmark fund performance against risk. Included a transaction review workflow with flagging logic to surface anomalies for compliance review, and drill-through investor detail by type and region to support LP reporting.
